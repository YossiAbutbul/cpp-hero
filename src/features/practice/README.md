# practice

`PracticeScreen` (#/practice): spaced review card + Practice Arena grid (one card per challenge type, unlocked once met).
`PracticeRun` (#/practice/run?mode=review | ?mode=arena&type=<type>, immersive): 5 challenges in the lesson session
chrome, then results. Review ends with `game.finishPractice()` (practice quest, active day). `#/practice?review=1` jumps straight into a review.
